InfiniteFuel - Station Fix

Objectif de cette version
=========================
- Reprendre la logique de la première version qui rendait la cuve
  de la station-service infinie.
- Corriger UNIQUEMENT le problème des voitures clientes considérées
  comme déjà ravitaillées.
- L'aéroport n'est volontairement PAS traité dans cette version.

Installation
============
1. Ferme le jeu.
2. Remplace complètement :
   ue4ss\Mods\InfiniteFuel
   par le dossier InfiniteFuel contenu dans ce ZIP.
3. Garde dans mods.txt :
   InfiniteFuel : 1
4. Lance le jeu normalement.

Aucun diagnostic à faire.
